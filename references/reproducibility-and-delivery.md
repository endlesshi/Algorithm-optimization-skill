# 低存储成本复现与交付

用途：登记实验、保存版本、重新运行、整理交付或审核复现承诺。来源于方法总结第四章、第七章交付部分与附录A/B。

## 保存边界

目标是在约定复现能力下，以较小存储成本恢复每个**已登记**版本。共享不变内容、记录变化、保留无法可靠重新生成的对象。成功、失败和撤回实验均登记；临时未记录编辑不在保证范围内。

| 层级 | 实际保证 |
| --- | --- |
| 源码 | commit、子模块、补丁、必要未跟踪文件与配置可恢复 |
| 构建 | 工具、依赖及命令可获得；区分功能等价和产物逐字节一致 |
| 功能 | 输入、golden、校验方式和执行环境可用，重跑通过相同标准 |
| 性能 | 硬件、状态、边界和环境相符，在有依据的波动范围内复现 |

承诺层级与已验证层级分开。留日志不是完成性能复现；镜像标签不是不可变版本；容器不包含宿主机驱动和物理设备。再次运行得到新观测，不能重建原次运行发生过的噪声或trace。

## 对象组织

优先沿用项目既有工具，仅在缺少必要能力时补小型记录。

| 对象 | 保留方式 |
| --- | --- |
| 源码、脚本与配置 | 可长期保留的Git提交或带基版本的补丁；记录生成源码所需输入 |
| 输入与golden | 内容哈希共享；可靠生成者保存生成器版本、参数、依赖及预期哈希，不只记seed |
| 工具与依赖 | 不可变版本/摘要和获取方法；不稳定可得或关键依赖归档 |
| ELF、指令和镜像 | 可验证重建者可缓存；部署/关键验收及无法精确重建的产物保留实际哈希 |
| 实验观测 | 原始计时样本、正确性、关键日志及错误；不只保留最快一次或平均值 |
| trace与图表 | 保留支持结论的必要原始证据；派生图保留脚本、参数和来源；删trace会降低原次图表复现能力 |

源码版本与运行ID分开，同一实现可有多种输入/环境/运行。manifest引用对象和相对路径，记录实际使用的产物。纠错追加勘误或新记录，历史原始证据不覆盖。对象不可变；避免可写硬链接导致多个实验被同时修改。

## 使用实验模板

[experiment-manifest.json](../assets/experiment-manifest.json) 是无依赖JSON起点，不是强制schema或执行器。已有格式能表达相同事实时直接沿用。

- `null`表示尚未记录/未知，不等于通过或无限制；不适用写明理由。空数组表示尚未登记条目，不表示已验证为空。
- 建立记录时填写真实实验ID、日期、目的、baseline和输入/环境引用；没有必要的信息可省略或引用项目主记录，避免重复维护。
- `hypothesis`承载原因、改动、预期机制和目标收益；候选选择依据及方法树路径与它关联。
- `objects`按需增加`id`、`kind`、`path`或`uri`、`sha256`，可再生成者增加配方、工具版本与预期哈希。引用必须能解析；路径相对manifest或明确声明的根目录。
- `measurements`条目注明指标、单位、边界/时钟域、原始样本或证据引用；`checks`条目注明验收标准、结果与证据。源码版本不能替代运行环境和初始状态。
- `commands`保存实际命令、工作目录及所需环境，不含秘密；权限只记录获取方式。模板本身不自动执行任何命令。
- 四类状态分别维护；`reproduction`中的承诺和实际验证分开。

报告从记录提取或引用事实，不另写一套不一致的数据。模板允许逐步补齐，但报告结论必须有对应证据。

## 恢复与清理

复现按“恢复准确源码/配置 → 核验对象与依赖 → 构建并比较约定产物 → 恢复初始状态并运行 → 校验并生成新记录”进行，新记录指向原实验。

不能只检查文件存在就宣称可复现。依赖暂不可得时说明阻塞层级，完成可做部分。重建工具不可用、许可证受限或设备退役都可能降低承诺能力。

迁移旧实验按“盘点 → 去重归档 → 建清单 → 验证恢复 → 清理重复”推进。仅在确认可恢复且获得任务授权时清理；仍被保留实验引用的对象和Git历史不能回收。去重不代替备份，也不要求一开始部署内容寻址服务。

## 交付

按 [delivery-template.md](../assets/delivery-template.md) 建一个总入口，引用既有记录：

1. 目标、最终状态、有效实现版本、原始和当前baseline。
2. 主要改动、适用条件、未完成项及已知限制。
3. 构建/运行/校验顺序、依赖和权限、预期结果。
4. 正确性、性能与资源代价；对应条件、范围和原始证据。
5. manifest/对象索引、承诺与已验证复现层级。
6. 上一有效版本和恢复步骤；涉及布局/接口/镜像变化时说明兼容与恢复顺序。

没有上一有效版本时注明不适用，不虚构回退能力。失败或缺条件也交付现状和证据，不冒充成功优化。

交付前检查链接、命令、版本与结论一致；已有检查足够时不重跑。测试后源码或配置改变时重新判断证据是否有效。泳道图、II和硬件报告只在支持对应结论时提供，不列成所有项目的固定必交项。
