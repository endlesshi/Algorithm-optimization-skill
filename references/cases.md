# 机制、前提与代价案例

用途：将通用方法树映射到具体工作。案例提炼自方法总结附录C/D；这里不附原实验工程，不承诺独立复现历史性能。表中的示例可能是已记录机制或假设候选，不能当作当前项目已通过的结果。

## Prefill、RMSNorm 与 Decode

| 场景/机制 | 方法归属 | 实施前提与定向检查 |
| --- | --- | --- |
| RMSNorm每个归一化范围的因子只求一次 | 算→工作需求→复用 | 明确token/head归一化边界；归约、epsilon、精度和广播行为一致 |
| 中间值在已有寄存器/ARB复用，消除UB往返 | 存→映射；关联访问次数 | 核算物理容量和生命周期，消费结束前不覆盖，不能把LPU寄存器单位推广到其他硬件 |
| RoPE逐元素旋转替代稠密矩阵表达 | 算→工作需求/单次实现 | 证明旋转结构和配对方式；计入系数提取、布局转换、舍入及接口成本 |
| 多head打包到向量/矩阵通道 | 算→映射与调度 | 每行结果及归一化独立；有效形状、供数和额外workspace匹配，而非增加无关计算填满通道 |
| KV固定布局并原地追加 | 存→访问需求/布局/映射 | 调用方兼容；检查连续追加、非对齐尾部、历史有效区及阶段切换 |
| GQA两颗Q共享同一KV块 | 存→映射与调度；关联复用 | 两个消费者完成前保留块；共享地址不保证实际只加载一次，检查生成指令/访问计数 |
| 完整head预取、UB转发、计算继续细分 | 存→请求形成/重叠；算→划分 | 搬运粒度与计算粒度可不同；外存字节不变也可能因请求更大而更快，核算新增片内搬运、槽位和生命周期 |
| 缩小或删除等待 | 算/存→协调 | 区分数据就绪与旧数据释放，检查跨阶段覆盖和执行语义；少同步指令不自动代表耗时减少 |

Decode记录中的方法启发：

- ARU实现RoPE后释放LMB，才允许规范化输入复用。资源释放与后续方案一起评价，不能脱离后续使用估计收益。
- X_norm加载次数减少71.875%，记录中的整层收益仅0～0.27%；应按整体影响排序。
- 完整head预取与输入切分可以作为一个协同假设。原记录某用例基线381086周期，仅预取243135，仅切分275113，组合241937；组合减少36.51%，两项独立降幅不能相加。
- 这些数字来自原方法总结引用的历史记录，用于说明方法；未在此skill发布时重跑，不能作为任意平台的预期收益或验收阈值。

## CPU/GPU、分布式与可修改硬件

| 候选 | 主归属 | 需要核对的代价 |
| --- | --- | --- |
| CPU/GPU重排循环、分块以提高复用 | 存→访问调度；算→映射 | 实际缓存/外存访问、向量化、寄存器压力、尾部和重排成本 |
| 将任务安排到数据所在节点 | 存→映射位置/路径 | 远程流量、负载不均、复制成本和通信/计算重叠 |
| ASIC增加乘法器 | 算→资源规模 | 可用并行性、面积、功耗、供数、互连和可实现频率 |
| ASIC增加SRAM bank | 存→访问接口 | 新端口能力、地址映射、bank冲突、仲裁及布局时序 |
| 加深硬件流水 | 算→内部执行结构 | 目标II与单任务延迟不同；寄存器、控制、频率和填充排空 |
| 专用RoPE数据通路 | 算→单次实现；关联资源组织 | 适用范围、系数供给、位宽、验证覆盖、面积及维护成本 |

以上后三类是设计候选，不是已经实现或得到收益的证明。硬件可变时才进入实施候选；固定硬件只能使用已有能力。

## 模型、单算子与系统收益不同

预捕获指令回放不执行真实控制核的动态生成/提交。完整模型还包含其他算子和主机工作。因而模型周期显著降低、板上单算子收益较小、完整对话收益更小可以同时发生，但具体原因仍需对应证据。

先核对三者实现、工作负载、频率、初始状态及计时边界，再检查完整系统的关键路径。不要从END接近DONE、单层时间乘层数或单张泳道图直接推出控制核/FFN的精确占比。无分模块trace时，报告确定的整体差值并保留归因不确定性。
